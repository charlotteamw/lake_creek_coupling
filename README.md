# lake_creek_coupling

This repository contains the data-processing, statistical-analysis, and figure-generation code for the manuscript:

**Habitat coupling by small fish across lake–creek habitats: a missing link in freshwater food webs?**

The analyses evaluate seasonal habitat coupling by small-bodied fishes, focusing on golden shiner (*Notemigonus crysoleucas*) and common shiner (*Luxilus cornutus*) in a connected lake–creek ecosystem. The scripts combine stable isotope data, acoustic telemetry detections, and seasonal/directional trapping data to quantify trophic, behavioural, and biomass-flux dimensions of habitat coupling.

## How to run the analyses

Open `lake_creek_coupling.Rproj` in RStudio and run scripts from the project root. Each script sets:

```r
file_path <- getwd()
```

and reads files using paths such as `Data/...`, `Figures/...`, and `Code/...`. Running from the project root is therefore important for the relative paths to work correctly.

Recommended script order:

1. `Code/0 - Functions.R`
2. `Code/1 - Figure 2 - Creek Map & Detections.R`
3. `Code/2 - Figure 3 - Seasonal Isotopes & Telemetry Analysis.R`
4. `Code/3 - Figure 4 - GAM Models.R`
5. `Code/4 - Figure 5 -  Biomass Flux.R`
6. `Code/5 - Supplement.R`

The main analysis scripts source the shared functions file automatically, so reviewers do not need to run `0 - Functions.R` manually first, although it is listed first because the other scripts depend on it.

## Script descriptions

### `0 - Functions.R`

This script contains helper functions shared across the repository. It is sourced by the main analysis scripts and is not intended to generate figures by itself.

Key functions include:

- `standard_error()`: calculates standard error while ignoring missing values.
- `print_emm_pairs_iso()`: prints estimated marginal means and Tukey-adjusted pairwise comparisons for isotope models across month and location.
- `print_emm_pairs_tel()`: prints estimated marginal means and Tukey-adjusted pairwise comparisons for telemetry models across season and release location.
- `calculate_prop_tp()`: calculates the proportion of lake-derived carbon and trophic position for selected fish species and tissue types using creek and lake mayfly isotope baselines.
- `create_time_series()`: creates a one-minute telemetry time series for each tagged fish, joining detections to the deployment period and carrying the last known location forward.
- `enriched_time_series()`: similar to `create_time_series()`, but used in supplementary telemetry-processing plots.

Relation to manuscript: this file provides the shared calculations underlying the isotope mixing estimates, trophic position estimates, telemetry residency estimates, and recurrence analyses used in the main figures and supplementary materials.

### `1 - Figure 2 - Creek Map & Detections.R`

This script generates the study-system map and receiver-detection visualization used for **Figure 2**.

Main steps:

1. Loads lake and stream spatial layers from `Data/Lakes_Streams/`.
2. Loads receiver metadata from `Data/receivers.csv`.
3. Loads cleaned telemetry detections from `Data/detections_clean_alldata.csv`.
4. Removes specified transmitter IDs from the detection data.
5. Calculates detection frequency by receiver.
6. Builds a movement network based on sequential changes in receiver detections for each fish.
7. Loads isotope baseline-coordinate data from `Data/baselines_coords_d13C.csv`.
8. Uses `IsoriX` to model and map spatial variation in baseline δ13C across the lake–creek study area.
9. Overlays receiver locations, scaled by detection frequency, on the waterbody/isoscape map.

Relation to manuscript: this script supports the spatial framing of the study system by showing the lake–creek habitat arrangement, receiver array, detection intensity, and spatial isotope baseline structure.

Output: the script currently builds the Figure 2 map in the plotting window. If reviewers need a saved file, add a `ggsave()` call at the end, or run the script interactively and export the plot from RStudio.

---

### `2 - Figure 3 - Seasonal Isotopes & Telemetry Analysis.R`

This script performs the main seasonal isotope and telemetry analyses and generates **Figure 3**.

Main isotope steps:

1. Loads isotope metadata from `Data/iso_metadata.csv`.
2. Filters to golden shiner and common shiner liver samples.
3. Uses `calculate_prop_tp()` to estimate:
   - proportion lake-derived carbon, and
   - trophic position.
4. Summarizes mayfly and mussel baseline isotope values by location and season.
5. Fits baseline isotope models for δ13C and δ15N.
6. Fits shiner isotope models for raw δ13C and δ15N.
7. Fits a beta-family model for proportion lake-derived carbon.
8. Fits a Gaussian model for trophic position.
9. Calculates estimated marginal means, pairwise contrasts, and seasonal/location deltas.
10. Uses DHARMa residual diagnostics for model checking.

Main telemetry steps:

1. Loads cleaned acoustic telemetry detections from `Data/detections_clean_alldata.csv`.
2. Removes selected transmitter IDs and receivers from the analysis.
3. Converts tag-step timing, release dates, detection dates, and tag-on/tag-off windows to date-time objects.
4. Applies a false-detection filter using `glatos::false_detections()`.
5. Removes fish/tag records with invalid or mismatched detection windows.
6. Builds one-minute location time series for each tagged fish.
7. Assigns observations to seasons.
8. Calculates seasonal habitat residency as the proportion of detected minutes spent in the fish’s release/target habitat.
9. Calculates seasonal habitat recurrence as the number of return events to the target habitat after an excursion.
10. Links telemetry records to fish total length.
11. Fits telemetry models for:
   - habitat residency, using a beta-family model; and
   - habitat recurrence, using a negative-binomial model.

Figure output:

The script combines four panels into `Figures/figure_3.jpg`:

- proportion lake-derived carbon,
- trophic position,
- habitat recurrence, and
- habitat residency.

Relation to manuscript: this script supports the central comparison of trophic and behavioural habitat coupling across seasons and release habitats.

### `3 - Figure 4 - GAM Models.R`

This script fits generalized additive models to telemetry detections and generates **Figure 4**.

Main steps:

1. Loads cleaned telemetry detections from `Data/detections_clean_alldata.csv`.
2. Removes specified transmitters and receivers.
3. Reclassifies transition detections as creek detections for the lake-versus-creek probability analysis.
4. Converts detection timestamps, release dates, and tag windows to date-time objects.
5. Applies the `glatos` false-detection filter.
6. Removes invalid tag windows.
7. Builds one-minute location time series for each tagged fish.
8. Calculates a binary response indicating whether a fish was detected in the creek.
9. Fits candidate GAM/GAMM models using cyclic smooths over day-of-year.
10. Compares models with and without random effects and AR(1) autocorrelation structure.
11. Selects the final model based on model fit and biological interpretability.
12. Generates predicted seasonal probabilities of creek detection with confidence intervals.
13. Identifies peak and trough periods in predicted creek-use probability.
14. Runs residual diagnostics, including checks for autocorrelation.

Figure output:

The script saves `Figures/figure_4.jpg`, showing the predicted probability of lake–creek detection/use through the annual cycle.

Relation to manuscript: this script supports the seasonal behavioural-coupling analysis by showing how creek-detection probability changes continuously through time rather than only by discrete season.

---

### `4 - Figure 5 -  Biomass Flux.R`

This script analyzes seasonal minnow-trapping data and directional trap data and generates **Figure 5**.

Main CPUE steps:

1. Loads minnow trap data from `Data/minnowtrap_data.csv`.
2. Filters to golden shiner and common shiner.
3. Aggregates catch and biomass by month, day, and location.
4. Calculates log biomass per trap as a CPUE-style response.
5. Fits a `glmmTMB` model testing month, location, and their interaction.
6. Uses Type III tests, estimated marginal means, and pairwise contrasts to assess seasonal and habitat differences.
7. Uses DHARMa residual diagnostics for model checking.

Main directional-flux steps:

1. Loads directional trap data from `Data/directional_traps_all.csv`.
2. Filters to golden shiner and common shiner.
3. Aggregates daily biomass by year, season, day, and movement direction.
4. Calculates log biomass flux.
5. Fits a model testing season, direction, and their interaction, while including year.
6. Uses Type III tests, estimated marginal means, and pairwise contrasts to assess seasonal and directional differences.

Figure output:

The script saves `Figures/figure_5.jpg`, combining:

- seasonal biomass per trap by lake versus creek location, and
- directional biomass flux by upstream versus downstream movement.

Relation to manuscript: this script supports the population-level/biomass-flux dimension of habitat coupling, complementing the isotope and telemetry evidence.

### `5 - Supplement.R`

This script generates supplementary telemetry-processing plots, especially abacus plots used to inspect acoustic detection histories.

Main steps:

1. Loads cleaned telemetry detections from `Data/detections_clean_alldata.csv`.
2. Calculates tag timing and valid deployment windows.
3. Applies the `glatos` false-detection filter.
4. Removes fish/tag records with invalid or mismatched tag-on/tag-off windows.
5. Builds enriched one-minute time series for each fish.
6. Assigns seasons to each time step.
7. Generates an all-tag raw detection abacus plot.
8. Generates per-transmitter raw receiver-level abacus plots.
9. Generates all-tag enriched time-series abacus plots.
10. Generates per-tag enriched time-series abacus plots.

Figure outputs:

This script writes supplementary telemetry diagnostic plots to:

```text
Figures/Telemetry Data Processing/receiver_abacus_plots/
Figures/Telemetry Data Processing/enriched_abacus_plots/
```

Relation to manuscript: these plots document telemetry data processing and help reviewers evaluate detection histories, receiver use, location transitions, and the enriched time series used in the behavioural analyses.

## Notes for reviewers

- The scripts are organized to follow the manuscript’s analytical structure: study-system mapping, isotope and telemetry analyses, continuous seasonal movement modelling, biomass flux, and supplementary telemetry diagnostics.
- The main ecological question is whether small-bodied fishes act as habitat couplers between lake and creek habitats through resource assimilation, movement behaviour, and seasonal biomass flux.
- Seasonal factors are generally ordered as Spring, Summer, and Fall.
- Habitat/location factors are generally ordered as creek and lake.
- Some scripts intentionally remove specified transmitter IDs and/or receivers before analysis. These exclusions are coded explicitly in the relevant scripts.
- Model outputs, estimated marginal means, pairwise contrasts, and diagnostics are printed to the R console as the scripts run.
